# Aconchego Pompéu

Site-cardápio do Restaurante e Pizzaria Aconchego (Pompéu – MG), com foco em SEO e GEO.

- Next.js (App Router) + TypeScript + Tailwind + Supabase
- Escopo e pesquisa de SEO em [`docs/`](docs/)

## Rodar localmente
```bash
npm install
cp .env.example .env.local   # preencha a publishable key
npm run dev                  # http://localhost:3000
```
